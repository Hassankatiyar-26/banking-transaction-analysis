# Banking Transaction Analysis using SQL

## 📌 Project Overview

This project analyzes banking transactions using SQL to extract meaningful insights about customers, accounts, deposits, withdrawals, and potential fraudulent transactions.

The goal is to use SQL queries to understand banking activity and support data-driven decision-making.

## 🎯 Project Objectives

* Calculate total transaction amounts.
* Analyze total deposits and withdrawals.
* Calculate net cash flow.
* Analyze customer and account activity.
* Identify dormant accounts.
* Detect potentially suspicious transactions.
* Analyze daily transaction trends using SQL.

## 🛠️ Tools & Technologies

* **Database:** MySQL
* **Language:** SQL
* **Concepts:** Aggregate Functions, WHERE, GROUP BY, JOINs, Subqueries, CASE WHEN, Date Functions, and Window Functions.

## 📊 Key Analysis Areas

1. Total Transaction Amount
2. Total Deposits
3. Total Withdrawals
4. Net Cash Flow
5. Customer and Account Analysis
6. Dormant Account Identification
7. Potential Fraud Detection
8. Daily Transaction Analysis

## 📂 Project Files

* `banking_transaction_analysis.sql` — SQL script containing database setup, table creation, and analytical queries.

## 💡 Key Learnings

* Writing SQL queries to analyze transactional data.
* Using aggregate functions and joins.
* Analyzing customer and account activity.
* Applying SQL logic to identify potentially suspicious transactions.
* Using window functions to compare daily transaction totals.
